**Findings** (5, highest value first):

1. **[Anchor §2 · ETU]** No `README.md` or `LICENSE` — the repo has `CLAUDE.md` (build
   instructions, architecture notes) but no standard README for a human discovering the
   repo, and no license file. *Fix: add a short README.md (purpose, install, run, test)
   and a LICENSE (MIT or LI's choice).*
   (MIT basis: Missing Semester — every shared repo carries a README and license)

2. **[Anchor §5 · ETU]** `scorer.py` duplicates `split_body()` from `engine.py` (~20
   identical lines). *Fix: import `split_body` from `conformer.engine` instead of
   re-defining it.*
   (MIT basis: 6.031 R4 — DRY / don't repeat yourself)

3. **[Anchor §4 · RFC]** Internal helpers in `engine.py` (`split_body`, `children`,
   `span`, `reorder`, `normalize`, `esc`, `text_of`) are module-level public names with
   no underscore prefix and no `__all__`. Consumers see 7 implementation-detail functions
   alongside the intended public API (`Conformer`, `JudgmentCall`). *Fix: prefix with
   underscore or define `__all__ = ['Conformer', 'JudgmentCall', 'STYLE_ALTERNATIVES']`.*
   (MIT basis: 6.031 R9 — narrow interfaces / information hiding)

4. **[Anchor §6 · SFB]** No tests for the `change:StyleName` decision path, error cases
   (corrupt input, missing template), or `_word_lock_exists()`. The 6 existing tests are
   strong integration tests but all take the accept-or-skip happy path. *Fix: add one
   test that exercises `change:ExcerptorQuote` and one that passes a truncated zip to
   `Conformer()` expecting a clean exception.*
   (MIT basis: 6.031 R3 — test boundary conditions, not just typical cases)

5. **[Anchor §5 · ETU]** Dead loop at `engine.py:141` — `for a in re.findall(r'<w:abstractNum ...', ...): pass` iterates but does nothing (the real work is the
   `re.finditer` on line 142). *Fix: remove the dead `for` loop.*
   (MIT basis: 6.031 R2 — dead code confuses readers about intent)

*3 minor items omitted (sys.path hack in test imports, unclosed file handle at
engine.py:598, single-letter variable density in regex-heavy passes).*
